4. Polymorphism – Polymorphism means “one name, many forms.”
One method or interface can have different implementations.
“Polymorphism allows us to use the same method name with different implementations."

Types:
Compile-time → Method Overloading
Run-time → Method Overriding

Example :
class Animal
{
    public virtual void Sound()
    {
        Console.WriteLine("Animal sound");
    }
}
class Dog : Animal
{
    public override void Sound()
    {
        Console.WriteLine("Dog barks");
    }
}


------------------------------------------------------------------------------------------
Method Overloading – Definition
Method Overloading means having multiple methods with the same name 
but different parameters in the same class.
Example :
class Calculator
{
    public int Add(int a, int b)
    {
        return a + b;
    }

    public int Add(int a, int b, int c)
    {
        return a + b + c;
    }

    public double Add(double a, double b)
    {
        return a + b;
    }
}
--------------------------------------------------
Method Overriding – Definition

Method Overriding means:
Same method name ✔️
Same parameters ✔️
Same return type (generally) ✔️
Parent method must be virtual, abstract, or already override
Child method uses override

 Example :
 class Animal
{
    public virtual void Sound()
    {
        Console.WriteLine("Animal makes a sound");
    }
}

class Dog : Animal
{
    public override void Sound()
    {
        Console.WriteLine("Dog barks");
    }
}
