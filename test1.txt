Interview Answer

OOP stands for Object-Oriented Programming. It is a programming approach where we organize the application around classes and objects.

In C#, OOP mainly has four pillars: Encapsulation, Abstraction, Inheritance, and Polymorphism.

1. Encapsulation – Encapsulation means hiding the internal data of a class 
and allowing access to it through controlled methods or properties.
In simple words:
“Keep data private and provide controlled access to that data.”
Example ATM :
public class BankAccount
{
    // Data is hidden from outside
    private decimal balance;
// Controlled way to modify balance
    public void Deposit(decimal amount)
    {
        if (amount > 0)
        {
            balance += amount;
        }
    }
    // Controlled way to read balance
    public decimal GetBalance()
    {
        return balance;
    }
}
Using the class:
BankAccount account = new BankAccount();
account.Deposit(1000);
Console.WriteLine(account.GetBalance());
------------------------------------------------------------------------------
2. Abstraction – Hiding implementation details and exposing only the required functionality. 
In C#, we achieve this using interfaces and abstract classes.

interface :
public interface IPayment
{
      // Validate card
        // Connect to payment gateway
        // Check balance
        // Process transaction
        // Save transaction
    void Pay();
}

public class CreditCardPayment : IPayment
{
    public void Pay()
    {
        Console.WriteLine("Payment done using Credit Card");
    }
}
---------------------------------------------------------------------
Abstract Class Example
public abstract class Animal
{
    public abstract void MakeSound();

    public void Eat()
    {
        Console.WriteLine("Animal is eating");
    }
}
public class Dog : Animal
{
    public override void MakeSound()
    {
        Console.WriteLine("Dog says Bark");
    }
}
Animal animal = new Dog();
animal.MakeSound();
animal.Eat();
------------------------------------------------------------------------

3. Inheritance – One class can acquire the properties and methods of another class. 
It helps with code reusability.

4. Polymorphism – One method or interface can have different implementations.
 In C#, it can be achieved through method overloading (compile-time) and 
 method overriding (runtime

Encapsulation vs Abstraction
Encapsulation	                          Abstraction
Protects/hides  data       	               Hides implementation details
Focuses on how data is accessed	        Focuses on what functionality is exposed
Uses access modifiers	                Uses interfaces/abstract classes
Example: private balance            	Example: IPayment.Pay()
